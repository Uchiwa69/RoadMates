# Pitch investisseurs RoadMates

Présentation d'environ 20 minutes, deux orateurs, dont plus de la moitié en démo.

- Version en ligne : https://claude.ai/artifact/YAzuVdnXHBdWziut4jgkgW
- Version PDF : `Pitch RoadMates.pdf`
- Préparation (minutage, questions des investisseurs) : `pitch-preparation-roadmates.md`
- Sources des diapos : `slides/`, dans l'ordre défini par `deck.json`. Les notes de l'orateur sont dans la balise `<aside>` de chaque diapo.

Ordre : titre, vision, résultats Discovery, user stories et personas, story map, Kano et MoSCoW, contraintes, solutions techniques, démo Léa, démo Karim, démo Monique, conclusion.
