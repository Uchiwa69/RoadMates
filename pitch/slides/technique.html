Personne 2. 1 min. Ce qu’on a mis en place : un prototype web en React et Vite, responsive, en ligne sur GitHub Pages, qui sert aussi de maquette. Les messages de groupe sont chiffrés en AES-GCM ; dans le prototype la clé reste dans le navigateur. Le paiement est simulé mais exact au centime. On l’a construit en une journée avec plusieurs agents IA en parallèle, chacun sur sa partie. Pour le MVP : code partagé web et mobile, API hébergée en Europe pour le RGPD, Stripe Connect, un prestataire de vérification d’identité, et un vrai chiffrement de bout en bout. Place à la démo, à travers nos trois personas.
